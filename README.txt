BEFORE YOU PRINT ANYTHING LARGE — PLEASE READ
  The source artwork supplied was 400 x 241 pixels. At real print
  resolution that is about 1 1/3 inches wide. Everything larger in this
  folder was enlarged from it, which is fine on screen and on a small
  letterhead crest, but it will look soft on a banner, a sign, a
  full-page cover, or anything foil stamped.

  Ask whoever created the crest for the original .ai, .eps, .pdf, or
  .svg file. If it no longer exists, have a designer redraw the crest
  as vector once. It is a few hours of work and never has to be redone.

NEVER
  Stretch, tilt, recolor, or add effects to the crest.
  Retype the Hebrew inside the artwork.
  Drop or alter the honorifics after either Rav's name.
  Re-export a logo from a Word file or a WhatsApp image.
